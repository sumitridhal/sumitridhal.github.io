## Deployment convention

The eight new projects use `<slug>-landing` project names on Vercel team `sridhals-projects` and are direct static deployments with no Git provider connection. Each site consists of `index.html`, `styles.css`, and `vercel.json`. CMSMark remains on its existing `cmsmark` project. Product applications themselves are not deployed by this workflow.
