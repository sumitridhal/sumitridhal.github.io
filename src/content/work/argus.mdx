Argus is a **local Meta-Agent SRE control plane**. Phase 1 is a POC whose success criterion is a single heal loop you can watch: create an agent, inject failure, open an incident, run SRE, approve a green patch, and return to healthy.

## Problem

Cloud-native demos often stop at “agent writes a PR.” Operators still need a closed loop they trust: health signals, a bounded repair turn, and a human gate before merge. Multi-agent platforms obscure that proof. Argus locks the POC to **one template, one supervisor, one approve path**.

## Approach

- **Stack split:** Next.js dashboard (`apps/web`) plus a long-lived Node supervisor (`packages/supervisor`) and CLI executors (`packages/executor`).
- **Template:** one TypeScript Hono HTTP agent with OTel and an `INJECT_FAILURE` hook — copy → optional `claude -p` customize → Docker.
- **Trigger:** Level-2 health/log poll with a thin OTel→SQLite store (no Grafana dependency for the POC).
- **Auth:** host Claude/Cursor CLI for meta/SRE turns; `ANTHROPIC_API_KEY` only inside agent containers when needed.
- **UI surfaces:** Agents / Incidents / Raw — nothing else in Phase 1.

## Tech stack

Next.js App Router, Node supervisor, Docker, Claude or Cursor CLI adapters, SQLite, OpenTelemetry, Hono agent template.

## Demo

```bash
cp .env.example .env
pnpm install
pnpm --filter @argus/executor build
pnpm dev:supervisor   # terminal 1
pnpm dev:web          # terminal 2 → http://localhost:3401
pnpm demo             # skipCli by default; DEMO_SKIP_CLI=0 for real CLI turns
```
