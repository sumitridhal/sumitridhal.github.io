Motion Forge is a **local intro and motion workspace**. Shaders are look references that feed HyperFrames and Studio — not a competing shader SaaS. The product bet versus effect.app is a Photoshop-like **layer stack** plus honest local export.

## Problem

Effect-style tools win on media → layers → export. Open shader libraries win on primitives. Neither gives a durable local loop for intro videos and stills with upload, composition, and FFmpeg output without cloud quotas.

## Approach

- **Web app in `apps/web`** with Paper shader canvases, Layers UI, and an Export drawer.
- **Assets v1:** capture 1920×1080 PNGs from shaders → `POST /api/assets` → browse on `/assets`.
- **P0 shipped:** multi-effect compositor (soft cap 4), media upload for image filters, seek+PNG frames → FFmpeg MP4 / PNG-seq.
- **Positioning:** effect.app = effects product; Paper = primitives; Forge = local intro workspace.
- **Deferred:** Figma bridge (ADR 0005), WebM, freemium watermarks (explicitly skipped — ADR 0006).

## Tech stack

Next.js workspace app, Paper shaders / Three.js, HyperFrames preview+render, FFmpeg export, GSAP for intro templates.

## Demo

```bash
cd ~/git/motion-forge
npm install
npm run dev          # apps/web
npm run preview:intro
npm run render:intro # → outputs/default-intro.mp4
```
