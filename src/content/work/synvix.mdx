Synvix turns a freewrite rant into a **voice-matched blog draft** using your own corpus and the local `claude` CLI. The wedge is not “a bigger model” — it is **corpus / load / draft**.

## Problem

Founders who publish already have a vault and a CLI. Generic rewriters flatten voice. Cloud writing apps fight local corpora and privacy. The status quo is duct-tape: paste context by hand and hope the draft still sounds like you.

## Approach

- **Freewrite Studio** (`/freewrite`): sidebar + chat + editable artifact.
- **`lib/corpus.ts`:** load voice samples from `/corpus`, auto-include `/drafts` (deduped, ≤6k).
- **`lib/claude-bridge.ts`:** spawn Claude with stream-json for create/revise prompts.
- **Persistence:** SQLite meta + chat; draft markdown on disk as the body of record.
- **Office-hours lock:** founder-as-user only for demand signal; defer social blocks, git push, emotion slider, Vercel hosting.

## Tech stack

Next.js (port 3008), Claude Code CLI, Node 22 `node:sqlite`, SSE `/api/ai/freewrite`, drafts CRUD APIs.

## Demo

```bash
cd ~/git/synvix
npm install
# Seed /corpus with ≥3 of your posts
npm run spike   # stream-json bridge
npm run dev     # http://localhost:3008/freewrite
```
