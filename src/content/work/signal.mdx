Signal is the **bookmark / RSS curation** surface inside a broader personal productivity workspace. Collect fresh technical links each morning, mark relevance, cache TLDR summaries, and optionally chat with a local `cursor-agent` from the Tauri desktop shell.

## Problem

Morning research sprawls across tabs and newsletters. Cloud readers own the corpus; digests require API keys before they are useful. Agents that can execute in the same tree need clear ask/plan vs run boundaries.

## Approach

- **Web app under `signal/`:** refresh feeds, review items, relevance marks, cached TLDRs.
- **Sources (v1):** Hacker News, Lobsters, Smashing Magazine, DEV JS, GitHub Blog, Product Hunt, CSS-Tricks — X deferred.
- **Workspace map:** `wiki/` for curated second-brain pages, `workspace/` for OKF-style state, `artifacts/` for run evidence.
- **Desktop:** Tauri wraps the local Next app; chat defaults to ask/plan; execution requires confirmation.
- **Automations:** launchd-friendly scripts for dashboard refresh, digests, meeting prep, Obsidian sync.

## Tech stack

Next.js + Tauri, plain Markdown wiki, local automation under `workspace/automation/`, optional `OPENAI_API_KEY` for TLDR.

## Demo

```bash
cd ~/git/data-ai/learning/signal-workspace
npm --prefix signal install
npm --prefix signal run refresh
npm --prefix signal run dev
# Desktop: npm --prefix signal run desktop:dev
```
