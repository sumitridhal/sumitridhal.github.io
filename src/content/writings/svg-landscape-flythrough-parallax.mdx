Scroll a flat illustration and it feels like a poster. Give each depth plane its own scale curve on one scrubbed timeline and the same art reads as **moving forward through space**—a 2.5D fly-through without a WebGL stage.

This note wires that pattern for a writing embed: **Locomotive Scroll v5** on `#smooth-wrapper` / `#smooth-content`, **GSAP ScrollTrigger** with **`scrollerProxy`**, and an **inline SVG** whose groups are named for depth.

## Architecture

Three scroll contexts stay separate on purpose:

1. **Document** — Lenis + `ScrollTrigger.scrollerProxy(document.documentElement)` (see [Driving Lenis from GSAP’s ticker](/writing/lenis-gsap-scroll-loop)).
2. **Embed shell** — `#smooth-wrapper` is the Locomotive wrapper; `#smooth-content` is the tall track (`4 ×` shell height ≈ 400vh of scrub range inside the box).
3. **Camera** — a sticky full-shell viewport holds the SVG while the track scrolls behind it.

```text
#smooth-wrapper  ← Locomotive + scrollerProxy target
  #smooth-content  ← 4× shell height
    .camera (sticky 100% shell)
      <svg>
        #layer-sky … #layer-foreground
```

Locomotive’s Lenis instance owns `scrollTop` for the shell. **`ScrollTrigger.scrollerProxy(shell, …)`** proxies getters/setters to that instance, and **`ScrollTrigger.update()`** runs on every Lenis scroll tick (plus Locomotive’s `scrollCallback`). Without the proxy, scrubbed progress would read native `scrollTop` and drift from what you see.

The implementation lives in [`useLocomotiveScrollTriggerEmbed`](../../hooks/useLocomotiveScrollTriggerEmbed.ts) and [`WritingLandscapeFlythroughPreview`](../../components/writings/WritingLandscapeFlythroughPreview.tsx).

## Parallax math (one timeline, position 0)

All layers share a single scrubbed timeline. Depth is **differential scale** (and a little `yPercent` so the focal point stays in the trees, not the geometric center of the SVG):

| Group | End scale | End `yPercent` | Role |
| ----- | --------- | -------------- | ---- |
| `#layer-sky` | 1.1 | 2 | distant sky |
| `#layer-mountains` | 1.5 | 8 | far lake + ridges |
| `#layer-trees` | 4 | 18 | mid pines + hills |
| `#layer-ground` | 4 | 22 | lake band + shoreline |
| `#layer-foreground` | 7.5 | 30 | grass flies past the lens |

`transformOrigin: 50% 65%` on every group so the fly-through focal point sits on the green hills rather than the geometric center of the square artboard. Tune `yPercent` if your composition’s vanishing point shifts.

## SVG prep checklist

The live demo uses a **896×896** inline export in [`WritingLandscapeFlythroughSvg.tsx`](../../components/writings/landscape/WritingLandscapeFlythroughSvg.tsx). The embed viewport stays **16:10**; `preserveAspectRatio="xMidYMid slice"` crops the top and bottom of the square art so the lake and meadow fill the stage width.

1. In vector software, group shapes into **Sky**, **Mountains**, **Ground**, **Trees**, **Foreground** (foreground = blades/fronds at the bottom edge).
2. Name layers so export ids match: `layer-sky`, `layer-mountains`, `layer-ground`, `layer-trees`, `layer-foreground`.
3. Export SVG (square artboard is fine), open in a text editor, copy paths into the five `<g>` wrappers.
4. Keep `viewBox="0 0 896 896"` (or your artboard size) and the five ids — GSAP queries them by name.

## Reduced motion

When `prefers-reduced-motion: reduce` is set, Locomotive is skipped, the shell scrolls natively, and layers **`gsap.set`** to a single mid fly-through pose (~60% of full scale) so the depth read remains without scrub choreography.
